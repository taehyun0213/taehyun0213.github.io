수정 → 다운로드 → 반영

영어·한국어 내용을 아래에서 수정한 뒤 content.json 다운로드를 누르세요. GitHub 저장소의 기존 content.json을 이 파일로 교체하고 변경사항을 저장하면 GitHub 홈페이지가 자동으로 갱신됩니다. 현재 홈페이지에 반영하려면 다운로드한 파일을 이 대화에 첨부하여 수정을 요청할 수도 있습니다.

이 화면은 수정할 파일을 만드는 도구입니다. 다운로드만으로 공개 홈페이지가 변경되지는 않습니다. 정상 형식의 수정 내용은 이 브라우저에 임시 보관됩니다. 오류가 있는 입력은 화면에 남으며, 마지막 정상 임시 파일은 유지됩니다.
